# Desktop 4.0.0-rc.1 Implementation and Acceptance Snapshot

## Scope and release decision

This snapshot implements the Desktop 4 target from frozen community base `5696033b7e08d27ca678c91bed70f36da96aa3fb`. It preserves the 3.5 feature baseline while changing the default local Runtime path to an authenticated operating-system pipe. The deliverable is a Windows x64 release candidate and not a Stable release.

The official Runtime is the exact reviewed `@deepseek-ai/dsh` 0.1.5-rc.2 package family from the public npm registry. No official DSH source checkout is modified or referenced by TypeScript configuration.

## Source acceptance completed before packaging

The continuous source regression completed with 18 of 18 suites passing in 592.6 seconds. Its final Node test suite reported 156 tests passed, 0 failed, and 0 skipped. This run covered real Electron behavior including native plugin pages, Dock and model failure recovery, window geometry and DPI, long conversations, native turn and tab navigation, mode switching, directory selection and uploads, Runtime lifecycle, particle rendering, preset protocol handling, and direct-start/recovery integration.

The final pre-package Desktop unit run reported 1,181 passed, 0 failed, and 2 skipped out of 1,183. Both skips were Windows symbolic-link permission cases and were not converted from failures or used to weaken an assertion. The final full packaged gate reruns the release-critical source suites against the exact packaged executable.

## Final artifact procedure

The tracked tree is committed before packaging. Packaging is then run once. The following gates operate on that unchanged artifact:

1. release directory and manifest verification;
2. packaged smoke and actual Runtime graph checks;
3. full unified Electron regression, including compiled NSIS upgrade and rollback lifecycle;
4. explicit Remote Gateway LAN isolation and authorization;
5. acceptance receipt generation with source commit and installer SHA-256;
6. final Authenticode status and checksum verification.

The generated receipt is `apps/dsh-desktop/dist/acceptance-evidence-<short-sha>.json`. It is a build artifact rather than tracked source so recording the outcome does not change the commit that produced the installer.

## Known release boundaries

- Local transport has no listening TCP port by default. Enabling Remote Gateway is an explicit user action and has its own authorization boundary.
- The no-listener WebRoute adapter is a bounded transition component, not a permanent second server implementation. Removal requires the exit conditions in the transport inventory.
- Source Homes remain intact after migration. Dependencies are rebuilt rather than copied, and failed destination validation rolls back staging without mutating the source.
- Unknown or incompatible third-party plugins are retained with visible status; they are not silently removed or reported as migrated.
- The local Windows package is unsigned unless the release manifest reports a valid timestamped signature. Unsigned candidates must not be advertised as Stable or as publisher-authenticated software.
- macOS is outside this Windows x64 acceptance and receives no implied release claim.
